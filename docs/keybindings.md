# Terminal Keybindings Cheat Sheet

```text
Interrupt                    Ctrl+C
Copy / Paste                 Ctrl+Shift+C / Ctrl+Shift+V
Command palette              Ctrl+Shift+P
Find                         Ctrl+Shift+F
Settings JSON                Ctrl+Shift+,
Focus mode                   Ctrl+Shift+Enter
Summon terminal              Ctrl+Alt+Space

New / Close tab              Ctrl+Shift+T / Ctrl+Shift+W
Next / Previous tab          Ctrl+Tab / Ctrl+Shift+Tab
Rename tab                   Ctrl+Shift+R
Move tab                     Ctrl+Shift+Left / Right
Direct tab                   Ctrl+Alt+1..8

Auto split                   Alt+Shift+D
Vertical / Horizontal        Alt+Shift+V / Alt+Shift+H
Zoom pane                    Alt+Shift+Enter
Focus pane                   Alt+Arrow
Resize pane                  Alt+Shift+Arrow

Previous / Next command      Ctrl+Alt+Up / Down
Bookmark                     Ctrl+Alt+M
Export buffer                Ctrl+Shift+E
Clear buffer                 Ctrl+Shift+L

Font + / - / reset           Ctrl+= / Ctrl+- / Ctrl+0
```

PowerShell/PSReadLine:

```text
History reverse / forward    Ctrl+R / Ctrl+S
Menu completion              Tab / Ctrl+Space
Beginning / end of line      Ctrl+A / Ctrl+E
Word navigation              Ctrl+Left / Ctrl+Right
Delete previous word         Alt+Backspace
Undo / Redo                  Ctrl+Z / Ctrl+Y
Clear screen                 Ctrl+L
```
